# Keyboard shortcuts

`Mod` is `Cmd` on macOS and `Ctrl` on Windows and Linux. All shortcuts except the line break and `Mod` + Click can be [changed](./configuration#keyboard-shortcuts).

## Files

| Command         | Shortcut          |
| --------------- | ----------------- |
| New file        | `Mod` `N`         |
| Open file       | `Mod` `O`         |
| Save            | `Mod` `S`         |
| Save as         | `Mod` `Shift` `S` |
| Export as PDF   | `Mod` `Alt` `P`   |
| Cycle themes    | `Mod` `Alt` `T`   |
| Choose language | `Mod` `Alt` `L`   |

## Editing

| Command           | Shortcut                         |
| ----------------- | -------------------------------- |
| Undo              | `Mod` `Z`                        |
| Redo              | `Mod` `Shift` `Z`                |
| Insert line break | `Mod` `Enter` or `Shift` `Enter` |

## Blocks

| Command           | Shortcut        |
| ----------------- | --------------- |
| Paragraph         | `Mod` `0`       |
| Heading 1 – 6     | `Mod` `1` … `6` |
| Bullet list       | `Mod` `8`       |
| Numbered list     | `Mod` `9`       |
| Indent list item  | `Tab`           |
| Outdent list item | `Shift` `Tab`   |
| Blockquote        | `Mod` `G`       |
| Horizontal line   | `Mod` `H`       |

## Text

| Command              | Shortcut      |
| -------------------- | ------------- |
| Bold                 | `Mod` `B`     |
| Italic               | `Mod` `I`     |
| Code                 | `Mod` `E`     |
| Insert or edit link  | `Mod` `K`     |
| Open link in browser | `Mod` + Click |

You can also create most of these by typing markdown. See [Format as you type](./writing#format-as-you-type).
