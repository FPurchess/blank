Keyboard shortcuts ​

Mod is Cmd on macOS and Ctrl on Windows and Linux. All shortcuts except the line break and Mod + Click can be changed.

Open fileMod O

Export as PDFMod Alt P
Export as WordMod Alt W
Page setupMod Alt U
Edit headerMod Alt H
Edit footerMod Alt F
Pages or page endsMod Alt V
OutlineMod Alt O
Cycle themesMod Alt T
Choose languageMod Alt L

Tables ​

CommandShortcut
Insert a tableMod T, arrows, Enter
Next / previous cellTab / Shift Tab
Add a row (in the last cell)Tab
New line in a cellEnter
Select cellsShift + arrow keys
Select the cell, then the tableMod A
Clear the selected cellsBackspace or Delete
Table mode, in a tableMod T

In table mode, the arrow keys insert rows and columns, Shift + arrows move them, and letters align (L C R), sort (S), merge (M) and switch headers (H). See Change a table for all keys.

Spell check ​

CommandShortcut
Turn spell check on or offMod Alt S
Next misspelled wordMod Alt N
Previous misspelled wordMod Alt Shift N
Open the menu at the cursorShift F10 or the menu key

See Spell check for what the menu offers.

You can also create most of these by typing markdown. See Format as you type.
